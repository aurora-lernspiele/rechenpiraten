# Die Rechenpiraten – Kinderversion

Lernspiel für die 3. Klasse: **Punkt vor Strich im Zahlenraum bis 100** mit allen vier Rechenarten.

Die Kinder segeln von Insel zu Insel, suchen die Punktrechnungen selbst, schreiben die Zwischenergebnisse wie im Heft unter einen Bogen und rechnen erst dann die Strichrechnung. Auf drei Bonus-Felsen prüfen sie als Fehlerdetektiv die Rechnungen von Smutje Fritz.

## Spielen

- **Im Browser:** `index.html` per Doppelklick öffnen. Keine Installation, kein Konto.
- **Online:** https://aurora-lernspiele.github.io/rechenpiraten/
- Läuft auf PC, Tablet und Whiteboard.
- **Als App:** Im Browser „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ wählen. Danach läuft das Spiel auch ohne Internet.

## Einstellungen dieser Version

- 8 Aufgaben pro Insel, dazu die Flaschenpost (Wiederholung schwieriger Aufgaben)
- Den Wind (Zeitvorgabe) wählt jedes Kind selbst: Flaute (ohne Zeit), Brise (40 s), Frischer Wind (25 s), Sturm (10 s) je Rechenschritt
- Spielerprofile mit Name und Bild legen die Kinder selbst an
- Ohne Töne, ohne Lehrerbereich
- Nach allen neun Inseln beginnt eine neue Runde

Mehr Infos für Lehrkräfte: [Kurzinfo.pdf](Kurzinfo.pdf)

## Datenschutz

Profile, Sterne und Goldtaler werden nur im Browser des jeweiligen Geräts gespeichert (localStorage). Es werden keine Daten an einen Server übertragen. Die Schriften werden von Google Fonts geladen; ohne Internet nutzt das Spiel eine Ersatzschrift.

## Veröffentlichen mit GitHub Pages

1. Neues Repository anlegen, z. B. `rechenpiraten`.
2. Alle Dateien aus diesem Ordner hochladen (`index.html`, `Kurzinfo.pdf`, `README.md`, `.nojekyll`).
3. Im Repository: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch `main`, Ordner `/ (root)`, speichern.
4. Nach ein bis zwei Minuten ist das Spiel erreichbar unter
   `https://aurora-lernspiele.github.io/rechenpiraten/`
